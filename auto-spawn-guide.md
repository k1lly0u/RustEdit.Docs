title: Auto Spawn Guide
---

Rusts spawn handler uses a spawn filter to determine where various spawn-able objects can spawn on a map

These spawn filters 

- *Splat* Will only spawn in areas with these splat types
- *Biome* Will only spawn in areas with these biome types
- *Topology Any* Will only spawn in areas that have any of these topologies
- *Topology All* Will only spawn in areas that have all these topologies
- *Topology Not* Will not spawn in areas that have any of these topologies
