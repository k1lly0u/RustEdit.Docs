RustEdit is a map editor for Rust. It creates new maps or open procedural maps the game
generates, lets you modify terrain, prefabs and spawn points, and saves a `.map` 
file a server can load.

## The short path

1. [Install RustEdit](installing-rustedit.md) and point it at your Rust folder.
2. [Make your first map](your-first-map.md) - generate a small one, change one
   thing, save it.
3. Load it on a local server and walk around what you made.
