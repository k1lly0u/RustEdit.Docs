## Minimum Requirements
**OS**: Windows 10+
**PROCESSOR**: AMD Ryzen 5 1400 or Intel Core i5-6600
**MEMORY**: 16 GB RAM
**GRAPHICS**: AMD Radeon RX 470, NVIDIA GeForce GTX 1060, Intel® Arc™ A580
**DIRECTX**: Version 11
**Rust installed through Steam**

## Download / Install
RustEdit uses a launcher program which will download RustEdit and also check for updates when launched.
You can download the launcher [here](https://files.rusthq.com/rustedit/RustEditLauncher.exe)

Run the launcher installer. 
Pick a installation folder 
- Avoid installing into Windows system folders so you don't have Windows permission issues later.
- Do not install into your Rust folder.

The first run of the launcher will download RustEdit. 
When it has finished press `Play` to start RustEdit.

## First run
Upon launching RustEdit you will be prompted to select your Rust install directory.

If you do not know where Rust is installed on your PC;
In Steam, right-click Rust in the Library tab and select `Properties`, navigate to `Installed Files` and click `Browse`.
This will open your Rust install folder on your PC. The path Steam opens is the one the editor wants.

-# If you open the folder selection dialog and it is bare, then you have likely run in to a Windows permission problem.
-# Either move the folder to a different location, or apply admin privileges to the launcher and RustEdit executables

## Updating
To ensure you are always updated, run RustEdit via the launcher and click the `Check for updates` button.
