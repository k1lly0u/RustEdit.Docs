# Localization

RustEdit has localization support, here you can find some translation files.


To install a translation file, download the desired language .json file below
and copy it to your RustEdit install location \Localization\ folder.
Then restart the application for it to register.


You can select the language from the language dropdown on the main menu (in the bottom left corner), 
or you can change language in the scene view from the Help/Localization menu.
